# AI Use Statement

## Project: Team Petix Portfolio Website

This AI Use Statement documents the role of artificial intelligence tools in the development, testing, refinement, and documentation of the Team Petix web portfolio project. The project includes the shared homepage, member profile pages, responsive styling, and supporting project documentation.

AI tools were used to support idea generation, code structure, documentation drafting, and refinement of design and writing. These tools were not used as a substitute for the team’s own review, responsibility, or academic accountability. All final content, code, and presentation choices were critically reviewed and adjusted by the team before submission.

## How AI was used

AI assistance was used in the following ways:

- Drafting and improving the overall page structure and content flow for the homepage.
- Suggesting semantic HTML organization for sections such as the hero area, team profiles, and contact form.
- Assisting with CSS layout ideas for responsive design, spacing, card styling, and sidebar navigation.
- Reviewing wording for project documentation and improving clarity in the project README.
- Checking for possible accessibility and readability issues, including labels, link text, contrast, and focus states.
- Helping refine student-friendly descriptions and summaries of the project deliverable.

## How AI-assisted outputs were evaluated

All AI-generated suggestions were treated as starting points, not final answers. Each member evaluated the outputs by checking:

- whether the content matched the actual project requirements,
- whether the HTML and CSS code were consistent with the final design,
- whether the wording was accurate and appropriate for an academic assignment,
- whether the implementation was easy to understand, maintain, and explain,
- whether any output required revision to reflect the team’s real work and goals.

AI-generated content was edited, corrected, and incorporated only after careful review. Any inaccurate or weak suggestions were removed or rewritten to reflect the true scope of the project.

## Academic and professional responsibility

Although the milestone was completed collaboratively, each member remains individually responsible for understanding the final project, the code submitted, and the documentation included in the deliverable. We recognize that AI can support design and writing tasks, but final ownership remains with the learner who submits the work.

We are accountable for:

- verifying the correctness of AI-assisted work,
- understanding what was submitted by the team,
- ensuring that all final output is truthful, relevant, and accurately attributed,
- taking responsibility for the final project quality and integrity.
