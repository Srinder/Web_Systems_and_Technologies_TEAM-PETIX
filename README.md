# Team Petix

A collaborative student portfolio website created as a web system and technologies project. This repository contains a team landing page and individual member profile pages built with HTML and CSS.

## Team Members

- Srinder Kour Singh
- Jasver Kour Singh
- Jonalyn Tumpong
- Ma. Carmela Paula Oreta

## Project Overview

This project showcases the Team Petix group through a shared portfolio hub. The website includes:
- a team homepage
- featured project sections
- member profile cards
- update and milestone content
- a contact section for inquiries or feedback

## Website Structure

- `index.html` - main homepage for the team
- `style.css` - complete styling and responsive layout
- `srinder.html` - profile page for Srinder Kour Singh
- `jasver.html` - profile page for Jasver Kour Singh
- `jonalyn.html` - profile page for Jonalyn Tumpong
- `carmela.html` - profile page for Ma. Carmela Paula Oreta

## Technologies Used

- HTML5
- CSS3
- Responsive web design (Grid & Flexbox)
- Web Accessibility Standards (WCAG)

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser to view the homepage.
